# FNICE-Hasher
A Character Map based encoder/decoder based on **MK Encoder-Decoder**:
<url>https://github.com/darkstarshine2011/MK-Encoder-Decoder</url>

## What's the difference between ***MK Encoder-Decoder*** and ***FNICE Hasher*** ? (🇬🇧en)
### - It work's exactly like *MK Encoder-Decoder*
#### - A new feture added(CharMap Generator): It generates CharMaps file using random library
#### - The app is colorfull now by using rich library which you can download it using *pip*
```bash
pip install rich
```

## تفاوت های ***MK Encoder-Decoder*** و ***FNICE Hasher*** چیست؟ (🇮🇷Fa)
### - دقیقا مثل *MK Encoder-Decoder* کار میکند
### - یک قابلیت جدید به نام CharMap Generator اضافه شده است: با استفاده از کتابخانه random فایل CharMap درست میکند
### - حالا برنامه با کمک کتابخانه rich رنگی است که میتوانید آن را با استفاده از *pip* دانلود کنید
```bash
pip install rich
```
