# FNICE-Hasher
A Character Map based encoder/decoder based on **MK Encoder-Decoder**:
<url>https://github.com/darkstarshine2011/MK-Encoder-Decoder</url>

## What's the difference between *MK Encoder-Decoder* and *FNICE Hasher* ?
### - It work's exactly like *MK Encoder-Decoder*
#### - A new feture added(CharMap Generator): It generates CharMaps using random library
#### - The app is colorfull now by using rich library which you can download it using *pip*
```bash
pip install rich
```
